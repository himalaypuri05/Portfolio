# 🌟 Himalay Puri - Developer Portfolio

An interactive, modern portfolio showcasing full-stack projects, skills, experience, and achievements of **Himalay Puri**.

## ✨ Features

- 🎨 **Multi-Theme Engine**: Switch between 5 themes (Midnight Indigo, Obsidian Luxe, Emerald Sage, Royal Champagne, and Studio Light).
- 🌌 **Interactive Particle Canvas**: Fluid particle mesh background that reacts to mouse interaction and adapts to theme colors.
- ⚡ **Interactive Terminal HUD**: Simulated developer CLI with custom commands (`help`, `about`, `skills`, `projects`, `contact`, `clear`, etc.).
- 🔊 **Web Audio Synth Effects**: Optional sound effects for UI interactions.
- 💼 **Comprehensive Showcase**:
  - **About & Philosophy**: Background, bio, and engineering ethos.
  - **Skills Matrix**: Categorized technical proficiencies (Frontend, Backend, Databases, Tools).
  - **Featured Projects**: Detailed cards with tech tags, live previews, and GitHub links (FIFA All Stars, iNotebook, NewsMonkey, TextUtils).
  - **Experience & Education**: Academic background and hands-on software development milestones.
  - **Hackathons & Achievements**: Highlights of competitive programming and hackathon projects.
  - **Contact & Socials**: Interactive message form and direct links.

## 🛠️ Built With

- **HTML5** (Semantic structure, accessibility, Open Graph metadata)
- **Vanilla CSS3** (Custom design tokens, glassmorphism, responsive grid & flexbox layouts, micro-animations)
- **Vanilla JavaScript (ES6+)** (Theme switcher, Canvas particle system, audio synthesizer, terminal emulator)
- **Font Awesome 6** & **Google Fonts** (Outfit, Inter, Fira Code)

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or run with a local live server:

```bash
# Using VS Code Live Server extension or Python simple HTTP server:
python -m http.server 8000
# Or using npx serve:
npx serve .
```
